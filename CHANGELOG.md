# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.2] - 2024-01-15

### Added
- Initial public release
- Command execution functionality
- Script scheduling capability
- Command completed event trigger
- Command failed event trigger
- Security validation for command execution
- Execution timeout support
- Working directory configuration
- System, configuration, and filesystem permissions

### Changed
- Enhanced error reporting for failed commands
- Improved command validation logic

### Fixed
- Edge cases in script scheduling
- Timeout handling for long-running commands

## [0.0.1] - 2024-01-01

### Added
- Initial development version
- Basic plugin structure
- Core integration with Allow2Automate
- Basic command execution capability
